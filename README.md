# 🐾 Trabajo Colaborativo en GitHub  
## Proyecto Web: Descripción de un Animal

---

## 📌 Objetivo

Implementar un proyecto web colaborativo sobre la descripción de un animal utilizando **Git** para el control de versiones y **GitHub Pages** para la publicación del sitio web.

El propósito es aplicar buenas prácticas de trabajo en equipo, manejo de ramas, commits descriptivos y despliegue en la web.

---

## 🌍 Descripción del Proyecto

Este proyecto consiste en el desarrollo de una página web informativa dedicada a la descripción de un animal (por ejemplo, la capibara).

La página incluye:

- 🖼 Imagen representativa  
- 📚 Información general (nombre común, nombre científico, tamaño, peso, etc.)  
- 🌿 Características principales (hábitat, alimentación, comportamiento, reproducción, etc.)  
- 🎨 Diseño visual con CSS y Bootstrap  
- 🌙 Modo oscuro / claro  
- 📂 Carga dinámica de contenido desde archivo `.txt`  

El sitio se publica utilizando **GitHub Pages** para que pueda ser accesible en línea.

---

## 🛠 Tecnologías Utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Bootstrap 5  
- Git  
- GitHub  
- GitHub Pages  

---

## 👥 Trabajo Colaborativo

El proyecto se desarrolla en equipo siguiendo estas prácticas:

- Uso de ramas (`feature`, `main`, etc.)
- Commits claros y descriptivos
- Pull Requests para integrar cambios
- Resolución de conflictos en equipo
- Revisión colaborativa del código

---

## 🚀 Publicación con GitHub Pages

El sitio se despliega desde la rama `main` (o `gh-pages`) usando GitHub Pages.

### Pasos para activar GitHub Pages:

1. Ir a **Settings** del repositorio  
2. Seleccionar **Pages**  
3. Elegir la rama principal  
4. Guardar cambios  
5. Acceder al enlace generado

Un sitio web funcional, correctamente publicado en GitHub Pages, desarrollado colaborativamente y con historial de versiones documentado.
